# Bright Quest illustrated worlds

Nine original scenes created on 28 September 2026 with the built-in `image_gen` tool. The user requested proper sourced or created graphics instead of abstract geometric decoration.

The direction is a detailed painted adventure book: tangible places, expressive children, natural forms, blue/teal accents and warm light. These are discovery illustrations, not instructional diagrams. Actual lesson diagrams, media and course content are unchanged.

| Asset | Primary use |
|---|---|
| `discovery-treehouse.webp` | Today and family sign-in |
| `winter-maths.webp` | Winter Maths and earlier maths lessons |
| `chemistry-lab.webp` | Chemistry and earlier Chemistry lessons |
| `grammar-garden.webp` | Grammar |
| `physics-workshop.webp` | Physics |
| `exam-expedition.webp` | Core exam catalogue |
| `challenge-observatory.webp` | ICAS |
| `focus-studio.webp` | Focus Studio and parent next step |
| `world-voyage.webp` | International Challenges and My Journey |

All are 1536 × 1024 pixels. WebP encoding at quality 86 preserves the original composition; no crop or visual edit was applied. Combined delivery size: 3,378,018 bytes. Browser layouts control the crop and lazy-load off-screen cards. There are no runtime external image requests.

The complete original generation prompts are in [prompts.json](prompts.json). Lossless PNG originals are retained beside the repository in `outputs/brightquest-uplift-qa-2026-09-28/originals/` and in the image tool's original output folder. Existing game artwork remains owned by its original game folders and is reused without modification.
